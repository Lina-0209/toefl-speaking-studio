# 使用指南

在页面顶部选择「中文 / English」切换界面，刷新后保留选择。题目原文、回答听写和个人素材保持原文；新生成的评分说明与推荐回答分析使用所选语言，已有报告的分析不自动翻译。处理评分期间语言选择暂时锁定，避免同一次流程混用语言。

1. **登录并设置 API**：在已部署的网站登录，在 API 设置中保存自己的 ztoken 密钥，确认账户支持所选文字、音频和推荐回答模型。
2. **选择素材（可选）**：不设置时自动使用作者共享素材。在「我的素材」可查看默认的 12 个核心短语和故事；上传 DOCX / TXT 或粘贴文本后，点击识别、核对并保存，即切换为个人素材。读取文件本身不调用模型；点击识别才发送文本并产生 API 费用。也可直接手动编辑，不使用识别。
3. **上传材料**：填写练习名称，上传题目截图（最多 4 张）和 11 段自己的回答录音。空白处支持 ⌘V / Ctrl+V 粘贴截图。录音可为 WAV、MP3、M4A，M4A 在浏览器中转换为 WAV。
4. **核对题目与录音**：第 1–7 题是复述原句，第 8–11 题是 Interview 问题。确认文字与每段录音的对应关系后开始评分。
5. **查看报告**：逐题查看 0–5 分、依据、建议、听写与录音。11 题完成后显示总分练习预估。Interview 推荐回答优先在原答案基础上改进，选用当前素材库中的两个核心短语。
6. **重试与复盘**：失败题目可单独重试；推荐回答缺失时单独生成。修改素材后，已有推荐回答需点「重新生成」。历史记录可重新打开或删除。

## 素材选择规则

- 无个人素材 → 使用作者共享素材。
- 保存个人素材 → 仅该用户使用个人库。
- 点击「使用作者共享素材」→ 删除该用户的个人库，恢复默认。
- 上传或识别但尚未保存 → 不影响正在使用的素材库。
- 两个核心短语用于支撑两个理由；故事仅作合适的举例，不代替理由。共享故事不会自动成为你的真实经历。
