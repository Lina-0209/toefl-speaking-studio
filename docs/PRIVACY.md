# 数据处理说明

本说明描述本仓库的实现，具体线上服务还取决于部署者与服务商的设置。

- 登录身份由 Sites 的 Sign in with ChatGPT 提供，使用站点内稳定的用户 ID 区分数据。
- 题目文字、逐题报告、个人素材和加密后的 API 密钥保存在 D1；题目截图和回答录音保存在 R2。
- 模型调用由服务端发送到 ztoken。题目识别会发送图片；评分会发送题目、实际回答录音和 ETS 样例录音；推荐回答会发送题目、原回答听写、评分反馈以及当前素材库。识别个人素材时会发送用户明确提交识别的文本。
- 每位用户的应用接口只能读写自己的练习、文件、密钥配置与个人素材。共享素材对所有用户相同，但不会包含其他用户上传的内容。
- API 密钥使用部署者设置的 AES-GCM 密钥加密保存，不通过 API 返回给浏览器。这不是端到端加密；部署管理员控制数据库、存储及服务端运行环境。
- 删除练习会删除其记录、已保存的图片和录音及该次练习的上传分块。删除个人素材会恢复默认共享库，不会清除已有报告中的推荐回答。数据是否存在服务商备份、保留多久，由部署者和服务商决定。
- 开源仓库只包含作者明确共享的静态素材；不含用户的 API 密钥、个人上传素材、答题录音或历史记录。

请在自己信任的部署中保存密钥和录音，并了解该部署及其上游服务的数据处理方式。
